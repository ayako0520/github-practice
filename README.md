# github-practice

GitHub勉強会向けの練習用リポジトリです。参加者は誰でも自由に

- Issueを立てる
- ブランチを作る / Forkする
- プルリクエスト（PR）を出す
- 自分や他の人のPRをレビュー・マージする

ことができます。壊れても気にせず、どんどん練習してください。

## このリポジトリでできること

| ディレクトリ | 内容 |
|---|---|
| `examples/` | 簡単なサンプルコード。1行直してPRを出す練習に |
| `docs/glossary.md` | IT用語集。誤字・説明不足があるので、見つけたら直すPRを出してみよう |
| `docs/self-introduction.md` | 参加者の自己紹介を追記していくファイル |
| `.github/PULL_REQUEST_TEMPLATE.md` | PRを出すときに自動で入るテンプレート |

## 参加のしかた（初めての人向け）

1. このリポジトリをForkする（右上の「Fork」ボタン）、または直接ブランチを切る
2. 好きなファイルを直す・追記する（誤字修正、コード1行変更、自己紹介追加など何でもOK）
3. 変更をコミットしてpush
4. `main` ブランチ宛にプルリクエストを作成
5. 他の参加者からレビューをもらう、または自分でマージしてみる

詳しい手順は [CONTRIBUTING.md](./CONTRIBUTING.md) を参照してください。

## ルール

- 荒らし行為・不適切な内容以外は自由。間違えても気軽にやり直せます
- 分からないことは遠慮なくIssueで質問してOK
- 自分のPRを自分でマージしてみる練習も歓迎です
