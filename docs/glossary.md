# IT用語集（みんなで直す用）

このファイルはわざと誤字や説明不足を残しています。見つけたら気軽にPRで直してください。追加したい用語があれば追記もどうぞ。

| 用語 | 説明 |
|---|---|
| リポジトリ | プロジェクトのファイルや変更履歴をまとめて保管する場所のこと |
| コミット | 変更を記録する操作。一つ一つの変更に短いメッセージを付ける |
| ブランチ | 本流（main）から分かれた作業用の線路のようなもの |
| プルリクエスト（PR） | 「この変更を取り込んでください」とお願いする仕組み |
| マージ | ブランチの変更を別のブランチ（多くはmain）に取り込むこと |
| フォーク | 他人のリポジトリを自分のアカウントにコピーすること。あやまって直接書き込む心配がない |
| コンフリクト | 同じ場所を複数人が変更して、自動で統合できなくなった状態 |
| レビュー | 他の人が出したPRの変更内容を読んで、コメントや承認をすること |
| Issue | バグ報告や質問、やりたいことを書いておく掲示板のようなチケット |
| CI | コードを変更するたびに自動でテストやチェックを走らせる仕組み（このリポジトリには未設定） |

> 編集のヒント: 説明が分かりにくい用語に説明を足す、誤字を直す、表に新しい用語を1行追加する、どれもPRの練習になります。
